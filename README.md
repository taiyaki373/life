# LIFE — 人生ゲーム

共有された「人生ゲーム調整版」をもとに、ユーザー指定の80マス・プレイヤー選択・リスク調整・終了時退職金を追加した日本語ブラウザゲーム。1〜4人の同じ画面でのプレイと、2〜4人のオンライン対戦に対応しています。

## 起動と検証

```sh
npm start
```

Node.js 18以降でポート3000に起動。http://localhost:3000 を開きます。依存パッケージのインストールは不要です。

```sh
npm test
```

Node.js 18以降でルールテストを実行します。

## 基本ルール

- 初期所持金30万円。学生1〜20マス、社会人21〜80マス。出目は1〜6。
- 社会人になるとお祝い100万円を受け取り、会社員・893・インフルエンサー・パチプロから職業を選択。
- 学生・職業・人生イベントは2〜3個の選択肢から行動を決定。選択前に金額・確率・状態の変化を表示。
- 選択が終わるまで次のターンには進みません。80マス目もイベントを選んでからゴール。
- 全員ゴール後に高級品を売却し、退職金を精算して、その後の所持金でランキング。同額は同順位。
- 所持金はマイナス可。借金があってもゲームを続けられ、最後まで負債が残ります。

## リスクとリターン

給与・就職祝い・終了時退職金は確定収入。それ以外の利益を狙うイベントには、失敗時の損失、初期費用、継続費用などの負担を付けています。

| 選択例 | 成功 | 失敗 |
| --- | --- | --- |
| 大きな成果報酬バイト | 60%：＋100万円 | 40%：−100万円 |
| 小さな成果報酬の仕事 | 80%：＋30万円 | 20%：−30万円 |
| 大きな案件 | 65%：＋250万円 | 35%：−200万円・バズ度−10 |
| 大きなバズ企画 | 60%：＋400万円・バズ度＋40 | 40%：−200万円・バズ度−15 |
| 大きな宝くじ | 25%：＋300万円 | 75%：−100万円 |
| 小さな宝くじ | 25%：＋90万円 | 75%：−30万円 |

多くの挑戦には見送る選択肢があります。損失リスクと収益の規模を比較して選べます。確率イベントの表示と実際の効果は同じデータから生成します。確率は毎回独立で、連続成功・連続失敗も起こります。

## 毎ターンの収支

- 生活費：学生5万円、社会人100万円。893は上納金50万円も毎ターン追加。
- 家族・資産の費用：子ども1人につき30万円、持ち家20万円、車10万円を毎ターン追加。
- 休みターンも生活費を支払います。給与・移動はありません。
- 通常ターンは移動先の時代に応じた生活費を払い、社会人の収入、そのマスの選択、結果の順で処理。
- 新しく増えた子ども・家・車の維持費は次ターンから適用。
- 会社員：給与200万円、昇給後250万円。893：250万円、昇格後300万円。昇給・昇格は重複なし。
- インフルエンサー：バズ度0〜20は100万円、21〜49は150万円、50〜79は250万円、80〜100は400万円。
- パチプロ：基本勝率50%、勝ち＋600万円・負け−400万円。所持金が少なくても負け額を全額差し引き、負債を0円に戻しません。打つ／打たないを毎ターン選べます。
- 次ターンの勝率変更は、休養や自分の判断で打たない場合も消化。
- 会社員の後輩との飲みは、出目1〜3の追加ロール。追加分は給与・生活費なし、イベントあり。
- 会社倒産は資産を半分にし、既に負債なら1.5倍にします。負債を自動的に減免しません。

## 退職金

退職マスはありません。会社員の旧退職金イベントは「資格取得」に置き換えました。

**全員ゴールした時に、各プレイヤーの高級品売却後の退職前所持金の40%を一度だけ支給します。** 全職業に適用し、1円未満を切り捨てます。退職前が0円以下なら退職金は0円で、負債はそのまま残ります。

- 退職前1000万円 → 退職金400万円 → 最終1400万円。
- 退職前−500万円 → 退職金0円 → 最終−500万円。
- 先にゴールした人は待機し、全員到着までは支給しません。
- 結果画面とログに退職前・退職金・最終額を表示。再読み込みで二重支給しません。

## 人生イベントと特殊イベント

結婚・出産・七五三・入学・卒業・葬儀・法事・金婚式など、23種類の共通イベント。色・アイコン・ラベルで表示し、職業イベントの代わりに発生します。婚姻・子ども・家・車の状態は選択によって更新され、プレイヤー情報に表示されます。未婚・子どもなしなら、関連するイベント名を旅行や親戚のお祝いへ置き換えます。

闇バイトの勧誘は12マス目を通過した学生ターンに一度だけ。断ると変化なし、引き受けると30%で＋1500万円、70%で−500万円・1ターン休み。警察スキップ権は使用不可。18マス目に止まると教師逮捕への対応を選択します。

893のセット品は50%で＋400万円、50%で警察。見つかった場合は−300万円・2ターン休み・イベント収入なし。警察スキップ権1枚で損失と休みを無効化し、収入400万円を獲得できます。権利の所持上限は2枚。

## 保存・実装

ログは右上の「人生の記録」からモーダルで表示。最大1,000件を保存。選択中も記録を確認でき、閉じると選択へ戻れます。

localStorageに進行・未決定の選択・精算状態を自動保存します。旧60マス版は現在地・所持金を引き継いで80マスまで続行。80マスの旧版は進行を維持し、未決定の旧退職金マスは資格取得へ変更。既に終了していた旧版は初回読込時に退職金を一度だけ精算します。

ルール処理は `game.js`、選択肢は `decisions.js`、画面は `app.js`・`index.html`・`style.css`。元資料の本文は `docs/rules-source.txt` に保存しています。マス配置・追加選択肢・人生イベント・生活費・リスク調整・退職金はゲーム独自の設定で、元資料の資産目安は保証しません。全金額はゲーム内のバブル風演出で、実際のバブル期の物価や現在の販売価格を再現するものではありません。

Google Fontsが利用できない場合はシステムフォントに切り替わります。ゲーム処理は外部サービスを使いません。オンライン対戦は同じNode.jsサーバーに接続します。


## バブル版の金額と高級品

従来の収入・費用・初期資金を実際に10倍へ変更。初期資金30万円、就職祝い100万円、会社員の給与200〜250万円、パチプロの勝ち600万円・負け400万円。値上がり・値下がりのリスクと負債は引き続き残ります。

80マスのうち46マス目に「ゴリゴリのロレックス購入」、58マス目に「ゴリゴリの高級車購入」を追加。どちらも2種類から購入するか、見送るかを選びます。借金で購入することもできます。

| 高級品 | 購入価格 | 維持費 / ターン | 売却時の好況 | 売却時の値下がり |
| --- | --- | --- | --- | --- |
| ゴールド・ロレックス | 600万円 | 5万円 | 70%：800万円 | 30%：200万円 |
| コレクターズ・ロレックス | 1200万円 | 10万円 | 45%：2200万円 | 55%：600万円 |
| フラッグシップ高級車 | 2000万円 | 50万円 | 70%：3200万円 | 30%：1000万円 |
| 限定スーパーカー | 4000万円 | 100万円 | 45%：9000万円 | 55%：1600万円 |

購入は現金を支払い、購入した次の通常・休みターンから維持費がかかります。追加ロールでは維持費も支払いません。高級車は既存の車と別の所有物で、既存の車がある場合は両方の維持費を支払います。

全員がゴールした時に高級品ごとに独立して売却額を抽選し、現金へ加算。その後、所持金の40%を退職金として一度だけ支給します。値下がりで負債が残った場合、退職金は0円です。売却結果・退職金・最終額はログと結果画面に保存し、リロードで再抽選・再支給しません。

保存バージョン5より前のデータは、所持金・負債・既払いの退職金を一度だけ10倍換算し、位置と選択状態を引き継ぎます。過去のログは当時の金額を保ち、換算通知を追加。新しい高級品マスで止まっていた未決定の旧イベントは高級品購入へ変更します。

高級品のゲーム内価格・維持費・売却額は `luxury.js` に定義しています。

## オンライン対戦

名前を入力して「ルームを作る」。友達には「招待リンクをコピー」で共有するか、同じサイトで6文字のコードを入力して参加してもらいます。2〜4人そろったらホストが開始。サイコロ・職業・イベントは自分のターンに自分の端末から操作します。ホストだけが全員の進行をリセットでき、やり直し後は同じメンバーで開始待ちに戻ります。従来のローカルプレイも利用できます。

`server.js` がルーム・ゲーム状態・乱数・権限を管理し、1秒ごとに全員へ同期します。クライアントから所持金や出目は送信できません。更新番号で二重送信と古い状態からの操作を拒否します。参加用トークンは各タブのsessionStorageに保存し、同じタブの再読み込みで選択途中から復帰できます。ネットワーク切断時は自動で再接続を試みます。退出するとそのタブの参加情報が削除され、開始済みルームへの新規参加はできません。

ルームはサーバーメモリに保存します。サーバーを停止・再起動すると消去され、24時間アクセスされないルームも期限切れになります。全員を同じサーバープロセスに接続してください。任意のポートは `PORT=8080 npm start` のように指定できます。

離れた友達と遊ぶには、このNode.jsサーバーをアクセス可能なHTTPS URLで公開する必要があります。Codespacesならポート3000を転送し、友達のアクセス権に応じてPortsから公開設定を行います。localhostのリンクは別の端末からは使えません。静的ファイルだけのホスティングには対応していません。

テストは `npm test`。オンラインテストは実際にローカルのHTTPソケットを開き、参加上限・ホスト権限・ターン制限・選択同期・再接続情報・重複操作・不正な入力を確認します。


## 思い出ボーナスと家族イベント

修学旅行、ごほうび旅行、家族旅行、記念日や趣味などの選択で「思い出」を獲得できます。思い出1つにつきゴール時に100万円を支給し、高級品の売却後・退職金の計算前に所持金へ加算します。選択肢には思い出の数とボーナス額を表示します。

結婚していない場合、36マス目は親戚の赤ちゃんのお祝いになり、自分の子どもは増えません。76マス目も子どもがいなければ親戚のお祝いに変わります。子どもが増える選択は既婚者だけに適用されます。
